# Life Sim v0.4

A browser-based life simulation prototype built with plain HTML, CSS, and vanilla JavaScript.

## What's new in v0.4
- Browser autosave with `localStorage` after meaningful actions.
- Manual save, export, and import remain available.
- Parents, siblings, children, aging family members, family bonds, and family time.
- Choice-based random life events with stat consequences.
- Tabbed interface for Life, Career, Money, Family, and Activities.
- Keeps the v0.3 systems: persistent stats, multi-year education, career requirements, job performance, promotions, debt/credit, investments, financed assets, relationships, business ownership, crime, aging, and health effects.

## Run locally
Open `index.html` in a modern browser. For the most reliable localStorage behavior, serve the folder with a tiny local server, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages
This folder is ready to commit to a GitHub repository and publish with GitHub Pages. Keep `index.html` at the repository root.
